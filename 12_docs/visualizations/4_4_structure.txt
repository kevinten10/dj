
+------------------------------------------------------------------------------+
|                         4/4 TIME SIGNATURE                                    |
+------------------------------------------------------------------------------+
| One bar has four beats:                                                       |
|                                                                              |
|   Beat:      1          2          3          4                               |
|   Feel:      STRONG     weak       medium     weak                            |
|   Common:    KICK       CLAP       KICK       CLAP                            |
|                                                                              |
| Phrase structure:                                                             |
|   4 beats  = 1 bar                                                            |
|   4 bars   = 1 phrase, or 16 beats                                            |
|   8 bars   = 1 section, or 32 beats                                           |
|                                                                              |
| Mixing tip: start transitions at the beginning of a 32-beat section.          |
+------------------------------------------------------------------------------+
